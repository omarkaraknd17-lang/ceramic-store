# Ceramic Store

This repository contains the source code and assets for the **Ceramic Store** website — an e-commerce catalog for ceramic and sanitary products (tiles, sinks, bathtubs, faucets, and related items).

## Status

This project is in the initial setup phase. No application code has been built yet. See [PROJECT_STATUS.md](./PROJECT_STATUS.md) for the current state of the project.

## Repository Structure

```
/docs             Project documentation
/data             Product and catalog data
/public           Static public assets
/public/products  Product images and media
```

## Branching

The `main` branch always represents a stable, working version of the project. Feature work happens on separate branches and is merged into `main` only when stable.
